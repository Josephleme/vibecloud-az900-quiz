## 🎧 Project Overview

Developed for the **#1MillionDevs Movement**, **Smart Quiz Builder** transforms the journey of preparing for the **Microsoft Azure Fundamentals (AZ-900)** certification into an engaging, interactive product. Built using rapid AI-assisted development paradigms, this application provides future cohorts with a structured pathway to mastering abstract cloud competencies.

## ✨ Core Application Capabilities

### 1. High-Fidelity Tiered Progression Track

The quiz architecture separates core exam modules into distinct difficulty curves, giving users deep test visibility:

*   🟢 **Tier 1: Basics** – Fundamental cloud concepts, infrastructure economies (CapEx vs. OpEx), and cloud benefits (Elasticity, Scalability).
*   🟡 **Tier 2: Advanced** – Architecture management, core compute services, virtual networks, and private cloud links (ExpressRoute vs. VPN).
*   🔴 **Tier 3: Most Advanced** – Multi-tenant platform governance, organizational compliance frameworks, Azure Policy, RBAC structures, and the Well-Architected Framework.

### 2. Dual-Channel Gemini Clarification Engine

To break down confusing jargon, every single question features two tailored AI assistants:

*   **In-App Analogy Explainer:** Instantly translates complicated tech terms into relatable, real-life analogies directly on the card.
*   **Chrome Gemini Gateway:** Seamlessly redirects users to the official Gemini web interface with a pre-configured, deep-dive prompt built to unpack the exact concept inside Chrome.

### 3. Error-Aware Infrastructure Matcher (Bonus Spice 🌶️)

A custom connecting game where students map core Azure tools (e.g., Cosmos DB, Blob Storage, Functions) directly to their operational traits.

*   **Live Visual Feedback:** Connections are instantly checked for validity.
*   **Active Error Tracing:** Correct nodes illuminate green, while misconfigured paths turn deep red (`border-rose-600`) to highlight weak knowledge boundaries.
